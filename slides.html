02 / The Problem
The Friction Tax

Designers want to prototype.
The toolchain blocks them.

Setup takes days, not minutes

Node versions, IDS peer dependencies, PostCSS, Vite compatibility — walls before a single component renders.

IDS breaks in modern tooling

Table, Dropdown, TextField have CSS Module hash conflicts in Vite. Workarounds aren't documented anywhere.

Figma and code drift apart

No feedback loop. Code goes stale, designs go stale, prototypes lose credibility with stakeholders.

AI agents don't speak Intuit

Claude, Cursor, Copilot guess at IDS props, ignore brand tokens, and skip D4D methodology entirely.

10 / Accessibility
Non-Negotiable

WCAG 2.1 AA is the floor,
not the ceiling.

Baked into agent instructions, component patterns, and verification checklists. Every prototype ships accessible.

Keyboard

Keyboard-first interaction

Every element reachable via keyboard. Focus traps in modals. Skip-to-content links. Logical tab order throughout.

Visual

Contrast & color

Text: 4.5:1 minimum. Focus indicators: 2px+, 3:1 contrast. Color never the sole indicator. Reduced motion supported.

Semantic

Correct HTML structure

<button> for actions, <a> for navigation. Landmarks everywhere. Sequential headings. ARIA only where needed.
