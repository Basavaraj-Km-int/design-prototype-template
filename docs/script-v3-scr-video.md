# Video Script V3 — McKinsey SCR Narrative

> **Duration**: ~3:45 (9 scenes)
> **Format**: Voiceover narration + on-screen text + terminal animations
> **Storytelling**: SCR (Situation → Complication → Resolution). Lead with the answer.
> **Tone**: Executive. Precise. Fact-dense. No filler. Every sentence earns its place.
> **Music**: Minimal. Clean electronic. No emotional manipulation. Confidence, not sentimentality.

## SCENE 3 — COMPLICATION: THE GAP (0:40–1:15)

**Voiceover:**
"The complication is structural, not tactical. First: access to AI tools is not the same as AI tools that work for Intuit. Every general-purpose agent hallucinates IDS — wrong prop names, wrong component APIs, wrong typography scale. It uses 'variant' instead of 'purpose.' It uses 'data-testid' instead of 'automationId.' It generates H1 headings for admin pages. Without Intuit-specific instruction, AI produces generic React that looks nothing like an Intuit product."

**Text on screen:**
`C1. AI agents don't speak Intuit.`

**Visuals:**
Terminal comparison:
```
WITHOUT harness:                    WITH harness:
<Button variant="danger"            <Button purpose="destructive"
  type="primary"                      priority="primary"
  data-testid="del">                  automationId="del">
✗ Hallucinated API                  ✓ Correct IDS API
```

**Timing:** 35 seconds. Music: tension, single low note added.
